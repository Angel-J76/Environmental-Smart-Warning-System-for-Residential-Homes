# Design Methodology

The system was built in three stages over a two-semester timeline (Aug–May).

## Stage 1 — Research & Theory *(Aug–Dec)*
- Identify user needs and review functional specifications
- Focus on identifying and understanding the required hardware and programming approach

## Stage 2 — Hardware Implementation *(Oct–Mar)*
- Design the layout of sensors, processors, and communication modules
- Plan the integration of wireless protocols and mobile app connectivity for alerts
- Design & hardware review, followed by implementation

## Stage 3 — Test & Verification *(Jan–May)*
- Build a working prototype using the selected sensors and hardware
- Integrate all components into a single system
- Perform final testing and verification against functional and safety requirements
- Test for reliability, accuracy, and response time

## Assumptions
- System is properly integrated into the home
- Proper installation is performed
- Wi-Fi is readily available
- Routine and proper maintenance is performed
- Hazard detection needs to occur in real time

## Known Constraints
- Unforeseen home conditions (drafts, humidity extremes, obstructions) may hinder sensor accuracy
- Alarm volume may not be loud enough to alert occupants in all room configurations
- The system will not function correctly without stable power, Wi-Fi, and routine maintenance
- A mobile device is required to receive remote notifications
